# 다크 테마 색감 재조정 및 보조 배경 제거

## 변경 목표

- 기존 Antigravity 계열 메인 배경은 유지
- 추가했던 보조 배경 레이어는 제거
- 전체 UI와 배경을 다크 테마 기준으로 다시 조정

## 구현 계획

- `public/index.html`
  - 보조 캔버스 `#bg-chaos` 제거
- `public/index.js`
  - 보조 배경 애니메이션 제거
  - 메인 Antigravity WebGL 배경만 유지
- 스타일
  - 전체 UI를 다크 테마에 맞게 조정
    - 배경 기본색, 카드 유리 패널, 드롭존, 버튼 그림자, 상태색 재설정
    - 메인 WebGL 파티클 색상을 어두운 배경 기준으로 보정

## 테스트 계획

- 시각 연출은 육안 검증 대상이므로 자동 테스트 작성하지 않음
- 대신 다음 정적 검증 수행
  - `deno fmt`
  - JS 파싱 확인
  - 로컬 서버에서 정적 파일 반영 여부 확인
