# 업로드 진행 물 채움 이펙트로 전환

## 변경 목표

- 업로드가 진행되는 동안 중앙 카드가 잔처럼 천천히 차오르는 인상 제공
- 실제 `/upload` 요청 구간에서만 보이는 전용 시각 효과로 제한
- 업로드가 너무 빨리 끝나도 애니메이션이 최소 시간 이상 보이도록 속도 상한 보장

## 구현 내용

- `public/index.html`
  - 카드 내부 비행체 오버레이를 제거하고 물 채움 전용 레이어로 교체
  - 카드 내부 요소는 오버레이 위로 유지하고, 카드 자체는 액체가 차오르는 동안
    내부에서만 시각 효과가 보이도록 `overflow: hidden` 적용
  - 장식적인 광택/그라데이션 대신 단색 반투명 액체 레이어만 남기도록 단순화
- `public/index.js`
  - 곡선 비행 기반 업로드 컨트롤러를 제거하고 물 채움 컨트롤러로 교체
  - 실제 `/upload` 요청 직전에만 시작
  - `fetch()` 대신 `XMLHttpRequest` 업로드 진행률 이벤트를 사용해 실제 전송
    바이트 비율과 수위를 연결
  - 진행률 이벤트가 늦어도 시작 직후 얕은 프라이밍 수위가 먼저 나타나도록 조정
  - 시작 즉시 눈에 띄는 기본 수위를 깔아 초반 지연 구간에도 효과가 바로 보이도록
    보강
  - 다중 파일 업로드 시 파일 목록은 업로드 중 유지되고, 완료 안내가 사라질 때
    함께 정리되도록 조정
  - 업로드가 끝나더라도 최소 표시 시간 전에는 완료 단계로 넘어가지 않음
  - 실제 진행률을 따르되, 너무 빠른 업로드는 최소 표시 시간에 맞춰 시각적으로만
    완만하게 제한
  - 최소 표시 시간 이후에는 상단까지 마저 채우고, 짧게 사라진 뒤에만 성공 또는
    실패 상태를 표시
  - 물 윗면은 `clip-path`를 프레임 단위로 갱신해 랜덤하게 출렁이는 형태로 표현
  - 완료 마감 구간은 현재 수위에서 자연스럽게 이어받아 부드럽게 끝나도록 조정

## 테스트 계획

- 시각 연출은 육안 검증 대상이므로 자동 테스트 작성하지 않음
- 대신 다음 정적 검증 수행
  - `deno fmt`
  - JS 파싱 확인
  - 로컬 서버에서 정적 파일 반영 여부 확인
