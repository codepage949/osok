# 수신측 연결 해제 시 업로드 상태 정리

## 변경 목표

- 수신측이 먼저 연결을 끊었을 때 업로더 UI가 계속 업로드 중으로 남지 않도록 수정
- 끊어진 수신자를 연결됨으로 오인하는 세션 상태를 방지

## 구현 내용

- `main.ts`
  - 수신 대기 중인 `/:key` 연결이 `abort` 되면 해당 세션을 다시 `null` 상태로
    되돌리도록 조정
  - 이미 끊긴 수신자에 대한 stale resolve 함수가 남아 잘못된 연결 상태를 만드는
    문제 방지
- `public/index.js`
  - 업로드 요청의 `XMLHttpRequest`에 `onabort` 실패 처리를 추가
  - 업로드 실패 또는 연결 해제 시 세션 키와 파일 목록을 즉시 지우고 실패 상태
    메시지를 표시하도록 조정

## 테스트 계획

- 다음 정적 검증 수행
  - `deno fmt`
  - `deno check main.ts`
  - JS 파싱 확인
