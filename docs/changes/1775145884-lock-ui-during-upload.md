# 업로드 중 추가 입력 잠금

## 변경 목표

- 업로드가 진행되는 동안 추가 파일 선택이나 텍스트 전송이 겹쳐서 들어가지 않도록
  방지
- 잠금 상태가 사용자에게도 보이도록 드롭존과 버튼의 비활성 표현 제공

## 구현 내용

- `public/index.js`
  - `isUploading` 상태와 `setUploadLocked()`를 추가해 업로드 구간의 공통 잠금을
    관리
  - 드래그앤드롭, 파일 버튼, 텍스트 버튼, 파일 입력 변경 이벤트에서 업로드 중
    재진입을 차단
  - `upload()`와 `handleFilesReady()` 내부에서도 재진입을 방지하도록 가드 추가
  - 잠금 시작 시점은 세션 생성이나 수신 대기 단계가 아니라 실제 `/upload` 요청
    직전으로 조정
- `public/index.html`
  - 드롭존, 버튼, 텍스트 입력에 비활성 스타일 추가

## 테스트 계획

- 다음 정적 검증 수행
  - `deno fmt`
  - JS 파싱 확인
  - 로컬 서버에서 비활성 클래스와 잠금 로직 반영 여부 확인
