# 파일 버튼 제거와 텍스트 전송 동선 단순화

## 구현 계획

- 드롭존이 이미 클릭 업로드를 담당하므로 별도 파일 버튼 제거
- 텍스트 입력란을 항상 노출해 파일 전송과 역할을 분리
- 세션 생성 및 수신 대기 중에도 UI를 잠가 중복 전송 흐름 방지

## 변경 사항

### `src/App.tsx`

- 파일 버튼 제거
- 텍스트 입력란을 항상 보이도록 변경
- 텍스트 전송 버튼 하나만 두어 액션 의미를 단순화
- 텍스트 입력값을 상태로 관리해 빈 입력 전송을 비활성화

### `src/hooks/useUpload.ts`

- 업로드 진행뿐 아니라 세션 생성, 수신 대기, ZIP 압축까지 포함하는 `isBusy` 상태 추가
- 파일/텍스트 전송 흐름 전체에서 재진입을 막도록 잠금 범위 확장

### `src/globals.css`

- 제거된 파일 버튼 스타일 의존 정리
- 텍스트 작성 패널 스타일 유지
- 제거된 토글/보조 버튼 스타일 정리

## 테스트 계획

- `deno task build`로 React/Vite 빌드 검증
- 육안으로 확인할 UI 변경이라 별도 자동화 테스트는 추가하지 않음

## 테스트 결과

- `deno task build` 통과
- 텍스트 입력란 상시 노출 구조로 변경 후 다시 `deno task build` 통과

## 리팩토링 검토

- 텍스트 입력 표시 상태 자체를 제거해 UI 상태를 단순화함
- 이번 변경 범위에서 추가 중복이나 분리 필요성은 크지 않아 후속 리팩토링은 보류
